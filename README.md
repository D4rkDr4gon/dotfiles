## Stack Tecnologico

```
WM:          Qtile (Python)
Barra:       Polybar
Terminal:    Kitty
Shell:       Zsh + powerlevel10k
Launcher:    Rofi
Compositor:  Picom (GLX + dual_kawase blur)
Editores:    Neovim (LazyVim) / Sublime Text
File Mgr:    Thunar
Info:        Fastfetch
```
