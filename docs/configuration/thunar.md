# Thunar -- File Manager

**Ubicacion**: `Thunar/`

## Archivos

| Archivo | Descripcion |
|---------|-------------|
| `accels.scm` | Atajos de teclado personalizados |
| `uca.xml` | Custom actions (Acciones de usuario) |

## Acciones Personalizadas (UCA)

| Accion | Comando | Atajo |
|--------|---------|-------|
| Open Terminal Here | `exo-open --launch TerminalEmulator %f` | -- |

## Atajos de Teclado

| Atajo | Accion |
|-------|--------|
| `Ctrl+T` | Nueva tab |
| `Ctrl+W` | Cerrar tab |
| `Ctrl+N` | Nueva ventana |
| `F2` | Renombrar |
| `F3` | Toggle split view |
| `F5` | Recargar |
| `F9` | Toggle side pane |
| `Ctrl+1/2/3` | Vista iconos/lista/compacta |
| `Ctrl+H` | Mostrar archivos ocultos |
| `Ctrl+L` | Abrir ubicacion |
| `Ctrl+F` | Buscar |
| `Alt+Left/Right` | Atras/Adelante |
| `Alt+Up` | Directorio padre |
| `Alt+Home` | Ir a home |
| `Ctrl+Q` | Cerrar ventana |
| `Ctrl+Shift+W` | Cerrar todas las ventanas |
